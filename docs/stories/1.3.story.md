## Por quê (contexto de negócio)

FR-7 do PRD / métrica §8.1 (projeto novo operacional em ≤ 2 min): hoje o consultor copia templates à mão. O `/onboarding` padroniza o primeiro minuto de todo projeto de cliente da 360IA.

## O quê (escopo)

Nova skill `skills/onboarding/SKILL.md` que, executada num projeto de cliente, cria a estrutura mínima do método: 3 arquivos de gestão (dos templates), `docs/stories/`, e um `CLAUDE.md` mínimo do projeto apontando para o frame.

**Não está no escopo:** git init/remoto, configuração de MCP, criação de stories de conteúdo, instalação do próprio plugin.

## Critérios de aceite

- [ ] AC-1: skill com frontmatter `name: onboarding` + `description` que dispara quando o usuário pedir "iniciar projeto", "bootstrap", "onboarding de cliente"
- [ ] AC-2: instrui copiar `templates/gestao/{MEMORY,PLANO_DE_ACAO,ROADMAP}.md` para a raiz do projeto alvo, preenchendo `{Nome do Projeto}` com o nome real (perguntar ao usuário se não for derivável da pasta)
- [ ] AC-3: cria `docs/stories/` (vazio, com `.gitkeep`)
- [ ] AC-4: gera `CLAUDE.md` mínimo do projeto: idioma pt-BR, frame dos 3 arquivos, referência ao fluxo /story→/sdc→/gate e à autoridade do shipper
- [ ] AC-5: **idempotência:** arquivo já existe → NUNCA sobrescrever; listar o que foi pulado
- [ ] AC-6: ao final, apresenta resumo do que foi criado/pulado e o próximo passo (`/story` para a primeira demanda)
- [ ] AC-7: recusa rodar dentro do próprio forge360 (proteção anti-recursão — comparar raiz do projeto com o nome/manifesto do plugin)

## Como (orientação técnica)

- É uma skill de **instruções** (Markdown), não script: o corpo orienta o agente principal a usar Read/Write/Bash nativos. Ver `skills/story/SKILL.md` como referência de tom e estrutura.
- Caminho dos templates: referenciar via raiz do plugin (`${CLAUDE_PLUGIN_ROOT}/templates/...` na instrução, com fallback: localizar o plugin instalado).
- O CLAUDE.md gerado deve ser CURTO (≤ 40 linhas) — Constituição Art. IV: contexto permanente vai para MEMORY.md, não para o CLAUDE.md.
- Conteúdo-modelo do CLAUDE.md gerado: incluir na própria skill como bloco de código a copiar.
